# Reborn Ready Corporation website

Live at https://rebornready.com (GitHub Pages).

Pages are built from `_src/pages/*.html` with a shared header/footer in `_src/build.py`.
Edit a page in `_src/pages/`, then run `python3 _src/build.py` and commit the generated `.html` files.
Contact info and the Charity ID live at the top of `_src/build.py`.
